## Get started

Whether you're exploring DAM as an open-source platform or using the hosted deployment at IBM, choose the path that's right for you.

<table>
<tr>
<td width="50%" valign="top">

### Open-source community

Run DAM on your own infrastructure, build agent workflows, or contribute to the project.

- **[Get started](https://github.com/dam-agents/dam)**  
  Explore the platform and deployment instructions.

- **[Run your own deployment](https://github.com/dam-agents/dam#run-your-own)**  
  Deploy DAM on your own Kubernetes cluster.

- **[Explore repositories](https://github.com/orgs/dam-agents/repositories)**  
  Discover platform components, integrations, Starter Kits, and examples.

  Read the project mission, governance, and contribution guidance.

DAM is licensed under Apache 2.0 and developed in the open. Issues, pull requests, and development happen in the [DAM repository](https://github.com/dam-agents/dam).

Whether you're running your own deployment or using DAM at IBM, explore the project, share what you're building, and help shape what's next.
